# 星野祝词 · 生日粒子

一场单文件的生日祝福粒子互动网页。打开后点「开始倒数」，从 3 到 1，粒子聚成爱心，烟花在两侧绽放；之后可以拖动星屑、轻点放烟花。

**在线体验：** https://huaiy36.github.io/birthday-stardust/

## 功能

- 3-2-1 粒子数字倒数与光环动画
- 爱心 / 蛋糕 / 星星 / 花束 / 月亮 / 文字 六种粒子形状
- 祝福文字、愿望短句、寿星名字实时生效
- 600–6000 颗粒子数量，5 套渐变预设，自定义起止颜色
- 轻点烟花、按钮放烟花、自动烟花
- 移动端安全区适配，320–430px 宽及桌面布局
- 自动 / 流畅 / 精致性能模式，低帧率自动降级，切后台暂停
- 单文件、无外链依赖、无摄像头或麦克风权限

## 使用

直接打开 `index.html` 即可。重新部署到 GitHub Pages 时保持 `index.html` 在仓库根目录。

设置会保存在浏览器的 localStorage 中。
